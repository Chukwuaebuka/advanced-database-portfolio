# Relational Schema: ECEWS SPEED Osun Hub (3NF)

PK = primary key, FK = foreign key, UQ = unique. Full constraints are in [create_tables.sql](create_tables.sql).

| Table                       | Columns                                                                                                                                                             | Keys / key constraints                                                                                                                             |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **LGAs**                    | `lga_id`, `lga_name`, `senatorial_district`, `state`                                                                                                                | PK `lga_id`; UQ `lga_name`; district ∈ {Osun Central, Osun East, Osun West}                                                                        |
| **Facilities**              | `facility_id`, `facility_name`, `lga_id`, `facility_type`                                                                                                           | PK; FK `lga_id → LGAs`; UQ (`facility_name`, `lga_id`); type ∈ {Primary Health Centre, General Hospital, Comprehensive Health Centre}              |
| **Clients**                 | `client_id`, `pepfar_uid`, `first_name`, `last_name`, `dob`, `gender`, `lga_id`, `date_registered`                                                                  | PK; UQ `pepfar_uid` (candidate key); FK `lga_id → LGAs`; `dob ≤ date_registered`                                                                   |
| **Community_Outreaches**    | `outreach_id`, `lga_id`, `outreach_date`, `location_name`                                                                                                           | PK; FK `lga_id → LGAs`                                                                                                                             |
| **HTS_Encounters**          | `hts_id`, `client_id`, `facility_id`, `outreach_id`, `testing_point`, `hiv_status`, `encounter_date`                                                                | PK; FK → Clients, Facilities, Community_Outreaches; exactly one of `facility_id` / `outreach_id` is set                                            |
| **ART_Enrollments**         | `art_id`, `client_id`, `facility_id`, `enrollment_date`, `clinical_stage`, `regimen_line`, `regimen`, `current_status`, `last_pickup_date`, `next_appointment_date` | PK; UQ `client_id` (1:1 with Clients); FK → Facilities; stage 1–4; `next_appointment_date > last_pickup_date`                                      |
| **ART_Pickups**             | `pickup_id`, `art_id`, `facility_id`, `pickup_date`, `months_dispensed`, `next_appointment_date`                                                                    | PK; FK → ART_Enrollments, Facilities; UQ (`art_id`, `pickup_date`); months ∈ {1,2,3,6}                                                             |
| **TB_Screening_Outcomes**   | `tb_screen_id`, `client_id`, `facility_id`, `screening_date`, `cough_status`, `fever_status`, `tb_status`, `tb_treatment_started`, `treatment_outcome`              | PK; FK → Clients, Facilities; treatment only if Confirmed-TB; outcome only if treated                                                              |
| **Lab_Viral_Load**          | `vload_id`, `client_id`, `facility_id`, `sample_collected_date`, `result_date`, `viral_load_copies`, `suppression_status`                                           | PK; FK → Clients, Facilities; `result_date ≥ sample_collected_date`; status must match copies (<1000 Suppressed, ≥1000 Unsuppressed, NULL Pending) |
| **v_outreach_yield** (view) | `total_tested`, `total_positive` per outreach                                                                                                                       | Derived from HTS_Encounters                                                                                                                        |

## Referential actions

- **`ON DELETE RESTRICT`** on reference data (LGAs, Facilities, Outreaches). A facility that still has clinical records cannot be deleted by accident.
- **`ON DELETE CASCADE`** from Clients to that client's clinical records. If a duplicate client registration has to be purged, its dependent records are removed with it and no orphans are left.
