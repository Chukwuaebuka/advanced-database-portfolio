# Portfolio 4: NoSQL and Advanced Data Models

| File                                                 | Purpose                                                                                    |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| [nosql-report.md](nosql-report.md)                   | Model design, embedding decisions, results, suitability analysis                           |
| [nosql-model.json](nosql-model.json)                 | A real sample document exported from the collection                                        |
| [export_from_postgres.sql](export_from_postgres.sql) | Relational → document migration (one document per ART client)                              |
| [mongo_setup.js](mongo_setup.js)                     | Collection with `$jsonSchema` validator                                                    |
| [mongo_queries.js](mongo_queries.js)                 | Point read, COLLSCAN → IXSCAN, aggregation, multikey index, atomic update, validation test |
| [evidence/](evidence/)                               | Import result and query output                                                             |

`data/client_records.ndjson` (~98 MB) is generated by the export script. It is git-ignored.

## How to run

```bash
psql -d speed_osun -At -f export_from_postgres.sql > data/client_records.ndjson
mongosh --quiet mongo_setup.js
mongoimport --db speed_osun --collection client_records --file data/client_records.ndjson
mongosh --quiet mongo_queries.js > evidence/mongo_output.txt
```
