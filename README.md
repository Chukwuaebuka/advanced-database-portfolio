## Case study in one paragraph

The hub stores HIV and TB programme data for ~90 supported facilities across the 30 LGAs of Osun State.

- **Users:** M&E officers, clinicians, outreach workers, lab technicians and programme coordinators.
- **Records:** HIV testing (facility and community outreach), ART enrolment, multi-month drug pickups, TB screening and viral load results.
- **Purpose:** to track retention, TB/HIV co-infection and viral suppression.

The full statement is in [portfolio-1-database-design/case-study.md](portfolio-1-database-design/case-study.md).

## Quick start

Requires Docker (or a local PostgreSQL 14+ and MongoDB 7).

```bash
# PostgreSQL
docker run -d --name adbs-pg -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=speed_osun \
  -p 5432:5432 -v "$PWD":/work postgres:16
pg() { docker exec -i adbs-pg psql -U postgres -d speed_osun -P pager=off "$@"; }   # works in bash and zsh
pg < portfolio-1-database-design/create_tables.sql
pg < portfolio-1-database-design/seed_data.sql          # ~10 s
pg < portfolio-2-query-optimisation/queries.sql
```

Each portfolio folder's README has its own run and test steps.
